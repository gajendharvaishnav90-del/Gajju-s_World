# World Simulator CLI

An interactive, object-oriented Python terminal application that simulates country-level management, economy, population growth, and resource allocation.

## Features
- **Turn-based Year Progression:** Dynamic annual feedback loops between economic policies and population health.
- **Resource Management:** Monitor and replenish food supply and water capacity.
- **Economic Controls:** Adjust taxation, monitor inflation, manage currency exchange valuation, and invest treasury funds into infrastructure.
- **Dynamic Parameter Overrides:** Directly set state parameters for custom scenario testing.
